Splitex

A modern and responsive footwear e-commerce website designed with a clean, stylish, and professional user interface.

Splitex focuses on presenting footwear products in an attractive way with product collections, promotional sections, responsive layouts, and modern visual effects.


📌 About the Project

Splitex is a front-end e-commerce website created to provide a modern online shopping experience for footwear products.

The website includes different product collections, promotional sections, product highlights, and responsive layouts for different screen sizes.

🚀 Getting Started

To run this project on your computer:

1. Clone the repository
git clone https://github.com/your-username/splitex.git
2. Open the project
cd splitex
3. Run the website

Open the index.html file in your browser.

For a better development experience, you can use the Live Server extension in Visual Studio Code.
